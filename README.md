# Pokémon Card Collection Manager 🎴

> Successfully completed frontend graduation project for my Full Stack Developer training at NOVI.

## About the project

Pokémon Card Collection Manager is a React application for Pokémon card collectors who want to search for cards and manage their personal collection.

Users can create an account, log in, search for Pokémon cards, view card details and add cards to their personal collection.

The application displays the current value of individual cards and calculates the total value of the user's collection.

## Features

- User registration and login
- Protected routes
- Search for Pokémon cards
- View detailed card information
- Add and remove cards from a personal collection
- Display current card values
- Calculate the total collection value
- Integration with an external Pokémon API
- Authentication through the NOVI Dynamic API

## Technologies

- React
- JavaScript
- React Router
- Axios
- Context API
- HTML
- CSS
- Vite
