# Pokémon Card Collection Manager 🎴

> Successfully completed frontend graduation project for my Full Stack Developer training at NOVI.

## About the project

Pokémon Card Collection Manager is a React application that allows users
to search for Pokémon cards and manage their personal card collection.

Users can create an account, log in, search for cards, view card details
and add cards to their collection.

## Features

- User registration and login
- Protected routes
- Search Pokémon cards
- View detailed card information
- Manage a personal card collection
- Integration with an external Pokémon API
- Authentication through the NOVI Dynamic API

## Technologies

- React
- JavaScript
- React Router
- Axios
- Context API
- HTML
- CSS
- Vite

## What I learned

This project gave me hands-on experience with building a complete React
application and connecting different parts of a frontend application.

I worked with routing, protected routes, authentication, application state,
API requests and handling data from external services.

It also taught me how important it is to structure an application clearly
as it grows.
